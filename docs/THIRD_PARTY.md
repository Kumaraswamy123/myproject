## React

The frontend vendors the React 18.2.0 and ReactDOM 18.2.0 browser production builds from the official npm/unpkg distribution.

- Files: `frontend/vendor/react.production.min.js`, `frontend/vendor/react-dom.production.min.js`
- License: MIT
- Project: https://react.dev/
